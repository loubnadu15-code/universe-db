# Number Guessing Game

Projet réalisé dans le cadre de la certification  
**FreeCodeCamp – Relational Database**.

## Description
Jeu en ligne de commande où l’utilisateur doit deviner un nombre aléatoire,
avec sauvegarde des scores dans une base de données.

## Objectifs
- Utiliser une base de données pour stocker des informations utilisateurs
- Écrire des requêtes SQL de lecture et d’écriture
- Gérer la logique d’un jeu simple en Bash

## Technologies
- Bash
- SQL
- PostgreSQL

## Contenu
- "number_guess.sh" : script principal du jeu
- "number_guess.sql": structure de la base de données

## Contexte
Projet pédagogique combinant logique algorithmique et persistance des données.
