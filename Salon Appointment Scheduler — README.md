# Salon Appointment Scheduler

Projet réalisé dans le cadre de la certification  
"FreeCodeCamp – Relational Database".

Description:
Application en ligne de commande permettant de gérer les rendez-vous d’un salon
à l’aide d’une base de données relationnelle.

Objectifs:
- Interagir avec une base PostgreSQL via un script Bash
- Gérer des entrées utilisateurs
- Insérer et interroger des données dynamiquement
- Concevoir une application simple basée sur SQL

Technologies:
- Bash
- SQL
- PostgreSQL

Contenu:
- "salon.sh" : script principal
- "salon.sql" : structure de la base de données

Contexte:
Projet pédagogique illustrant l’intégration de SQL dans une application simple.
