# Periodic Table Database

Projet réalisé dans le cadre de la certification  
"FreeCodeCamp – Relational Database".

## Description
Ce projet consiste à interroger une base de données représentant le tableau périodique
des éléments chimiques à partir d’un script en ligne de commande.

## Objectifs
- Écrire des requêtes SQL conditionnelles
- Gérer des arguments en ligne de commande
- Afficher des informations structurées à l’utilisateur

## Technologies
- Bash
- SQL
- PostgreSQL

## Contenu
- "periodic_table(1).sql" : structure de la base de données
- element.sh : script Bash d’interrogation de la base

## Contexte
Projet pédagogique visant à renforcer la maîtrise des requêtes SQL.
