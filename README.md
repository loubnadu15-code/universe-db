Ce dépôt contient mes travaux réalisés dans le cadre de ma certification  
"FreeCodeCamp – Relational Database".
https://www.freecodecamp.org/certification/fcc-loulou/relational-databases-v9

Ces travaux illustrent la conception, la manipulation et l’interrogation de bases de données relationnelles à l’aide du langage SQL.

Objectifs:
- Concevoir des bases de données relationnelles
- Créer et gérer des tables et relations
- Écrire des requêtes SQL complexes
- Manipuler des données avec PostgreSQL

Technologies utilisées:
- SQL
- PostgreSQL
- Bash
- Git

Projets:
- Celestial Bodies Database
- World Cup Database
- Salon Appointment Scheduler
- Periodic Table Database
- Number Guessing Game

Contexte:
Travaux réalisés dans un cadre pédagogique et présentés à des fins académiques et de portfolio.
